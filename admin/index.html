🗄️ Supabase Setup Guide

Why Supabase? Right now, announcements and contact submissions are stored in localStorage (browser-only, lost on refresh). To make them persistent across devices and sessions — and to make the admin panel actually useful — you need a backend database. Supabase is free for small projects and requires zero server setup.

📋 What to do (step by step)

  1. Go to supabase.com → Create a free account → New project.
  2. Create two tables in the Table Editor:
    • contact_submissions: id, name, email, year, subject, message, created_at
    • announcements: id, title, category, body, event_date, created_at
    • resources: id, title, category, link_url, description, created_at
  3. Go to Settings → API → copy your Project URL and anon public key.
  4. Paste them into supabase-config.js (create this file in the root).
  5. In shared.js, uncomment the Supabase blocks for contact form submission and announcement loading.
  6. In admin/index.html, uncomment the Supabase query blocks.

📄 supabase-config.js (create this file)

// supabase-config.js — place in project root
// Include via: <script src="supabase-config.js"></script>

const SUPABASE_URL  = 'https://YOUR_PROJECT_ID.supabase.co';
const SUPABASE_ANON = 'YOUR_ANON_PUBLIC_KEY';

// Then in any page that needs DB access:
// const db = supabase.createClient(SUPABASE_URL, SUPABASE_ANON);

🔐 Auth / Row Level Security

Enable RLS on both tables in Supabase.
• contact_submissions: Allow anonymous INSERT (so the form works without login). Restrict SELECT to authenticated users only (admin).
• announcements: Allow anonymous SELECT (so the public site can read them). Restrict INSERT/DELETE to authenticated users only.
